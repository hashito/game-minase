# 企画メモ：水無瀬病院 ― 七番の瓶

2026-11-16 作成。game-kit の [作る順番](https://github.com/hashito/game-kit/blob/main/docs/build-order.md) の S0。作者の案（廃病院・肝試しの二人組が「奥にあるモノを持って来い」と脅される・廃病院の謎を解いて終わる・キメラが襲ってくる・地下室と長い地下通路・屋外なし・排水と雨の水がテーマ・ホルマリン漬けとカルテ）から、残りを設計した。

## 1. 一行で

- 題名（決定）／英題：水無瀬病院 ― 七番の瓶 ／ Minase Hospital: Jar Number Seven
- 一行の売り：大学一年の戸川湊は、幼なじみの篠原ひなたと心霊動画を撮りに入った雨の廃病院で、地元の先輩・黒木に携帯を取り上げられ、正面の扉を鎖で閉められる。「地下の標本室の、七番の瓶を持って来い」。水につかった地下と長い通路の先で、水の中を動く「あれ」に追われながら、二十七年前の台風の夜にこの病院で起きたことを解き明かす一人称3Dホラー。
- 題材：オリジナル。病理標本（ホルマリン漬け）の無断保存、病院の排水設備（排水ポンプ・止水弁・防水扉）。実在の病院・人・事件とは関係しない。

## テイスト

- テイスト: standard（写実寄りの暗い病院。白いタイルと緑のリノリウム、雨漏りの水たまり、地下は水と錆）

## 2. 主人公と目的

- 主人公：戸川 湊（とがわ みなと）、19歳、大学一年。声あり、顔なし。
- 相棒：篠原 ひなた（しのはら ひなた）、19歳、幼なじみ。心霊動画のチャンネルをやっていて、今夜の撮影に湊を誘った。無線機を二台持って来た。地下の階段で足首をひねり、ポンプ室に残ってポンプを動かし、無線で湊を支える。
- なぜ帰らないか（K-03）：黒木たちに携帯を取られ、正面の扉を外から鎖で閉められた。裏口も窓も板で打ちつけてある。瓶を持って来るまで鎖は外さないと言われた。
- 黒木（くろき、22）：地元の先輩。去年、弟の蓮が肝試しでこの病院の地下に入り、出てきてから一言も話さず、紙に「7」とばかり書くようになった。自分は地下まで行けなかった。弟が何を見たのか確かめたくて、二人に七番の瓶を取りに行かせる。
- 最後に理解すること：(1) 七番の瓶の中身は、浅井庄一（1996年に死亡）の心臓。病理医の葛城が、家族に黙って標本にしていた。(2) 庄一の娘で検査技師の浅井早苗は、1999年9月15日の台風の夜、父の心臓を取り戻しに地下の標本室へ降りた。(3) 水が上がると、葛城は研究棟側の防水扉を閉めた。早苗が中にいると知っていて。早苗は「増水した川に流されて行方不明」とされた。(4) 水の中の「あれ」は、早苗と、割れた瓶の中身が一つになったもの。七番の瓶を持ち出す者を、水の中を追う。

## 決まり（A15：一文で）

**あれは、水のある所しか進めない。止水弁を回して水を抜けば、そこで止まる。**

- 止水弁：地下の通路の壁ぎわにある、赤いハンドルの弁。[E] で回すと、その前後の床の水が排水溝へ抜けて、乾いた帯ができる。あれは乾いた帯を越えられない。ただし雨水がしみ出して、水はしばらくで戻る（戻っていく様子が見える）。
- ロッカー：通路のロッカーは床より一段高い台の上にある。中に入れば足が水から上がり、あれは見失う。
- 防水扉：本館と研究棟の通路のあいだの厚い鉄の扉。ハンドルを回して開け閉めする。閉めれば水も、あれも通さない。

## 5. 怖さ・手応え

- あれ：白衣の切れ端をまとい、何人ぶんもの手と、濡れた長い髪。腰から下はいつも水の中。水のある所を這うように速く進む。
- 最初の遭遇は教える場面：通路の二枚目の防水扉の窓の向こう、水の満ちた側にあれが現れ、窓を叩く。ひなたがポンプで水を抜くと、あれは水といっしょに沈んで退く（水のない所へは来られない）。すぐ先で止水弁の練習（失敗しても死なない）。本番は瓶を取ったあと。
- 手応え：発電機（pump-gauge）、無線（tune-radio）、防水扉のハンドル（timing）、瓶を持ち上げる（steady-hand）、早苗の日誌の順番（order-steps）、標本と名前の照合（sort-items）、最後の四つの問い（間違えると水が上がり、ひなたの押さえる弁がもたなくなる）。

## 6. 範囲

- 部屋：一階 7、地下（本館）6、通路 6 区間と標本室。屋外なし。雨は屋内の雨漏り・排水口の音・壁の水として。
- 通路：約150 m。行きは走れない（床が濡れて滑る）ので約100秒。10秒ごとに何かが起きる。帰りは追われて走る。
- 話す人（顔写真）：ひなた、黒木（鎖のすき間の顔）、浅井早苗（あれ）、主人公（顔なし、声あり）。
- 寄り道：(1) 浅井早苗の日誌 三枚 → 日付の順に並べる → E3 の条件 (2) 水の通路の排水口の格子 三つ → 帰りに水の戻りが遅くなる
- 1回の目標時間：30〜45分。PC／スマホ両方。
